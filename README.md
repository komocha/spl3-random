# spl3-random

スプラトゥーン3のブキをランダムで選ぶ Web ページ（非公式ファンツール）です。

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルドやサーバーは要りません。
GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチのルートを指定してください。

## できること

- 全174種（GameWith「全武器一覧」より）から、ブキ種（11種）をしぼって抽選
- 結果にサブとスペシャルも表示
- 参加者の名前を入れると、その人数分（1〜8人）のブキを一人ずつ抽選（同じ回の被りなしを選べる）
- 前回と同じブキを避ける、レプリカ（オーダー・ヒーローなど）を含めるかを選べる
- ブキを個別に抽選から外せる
- 直近10回の結果を表示（設定と結果はブラウザの localStorage に保存）

## Discord に送る

抽選結果を Discord のチャンネルに送れます。

1. Discord のチャンネル設定 → 連携サービス → ウェブフック で Webhook を作り、URL をコピーする
2. ページの「Discord に送る」に URL を貼り、「結果を送る」を押す（「抽選のたびに自動で送る」も選べる）

Webhook URL はその場の入力欄だけで使い、ブラウザにもコードにも保存しません。ページを開き直すと空に戻ります。
名前に `@everyone` などが入っていても、メンションが飛ばないようにしています。
送信はブラウザから Discord へ直接行うため、GitHub Pages や手元で開いた `index.html` から使ってください（Claude の共有ページからは外部への通信が止められていて送れません）。

## デザイン

見た目はすべて `theme.css` にまとめています。攻略本の「ブキ カタログ」ページの誌面から、次の決まりを取り出して変数（`:root`）と部品のスタイルにしました。

- 地は黒に近いチャコール。四隅にイエローグリーンと紫のインクが飛ぶ
- 節の見出しは、イエローグリーンの帯に黒の極太文字（▶ 付き、少し傾ける）
- ブキ名は黒い板に白の極太文字。上にブキ種のタグ
- 「サブウェポン」「スペシャルウェポン」はイエローグリーンのラベル付きの枠
- 項目名は明るいグレーの箱に黒文字

## ブキ一覧の更新

ブキの一覧は `index.html` の中の `DATA`（ブキ種ごとに「名前|サブ|スペシャル」をカンマで区切った文字列）にあります。
ブキを足すときは、該当するブキ種の文字列に名前を追加してください。
