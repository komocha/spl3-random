# spl3-random

スプラトゥーン3のブキをランダムで選ぶ Web ページ（非公式ファンツール）です。

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルドやサーバーは要りません。
GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチのルートを指定してください。

## できること

- 全174種（GameWith「全武器一覧」より）から、ブキ種（11種）をしぼって抽選
- 結果にサブとスペシャルも表示
- 1〜8人分を一度に抽選（同じ回の被りなしを選べる）
- 前回と同じブキを避ける、レプリカ（オーダー・ヒーローなど）を含めるかを選べる
- ブキを個別に抽選から外せる
- 直近10回の結果を表示（設定と結果はブラウザの localStorage に保存）

## ブキ一覧の更新

ブキの一覧は `index.html` の中の `DATA`（ブキ種ごとに「名前|サブ|スペシャル」をカンマで区切った文字列）にあります。
ブキを足すときは、該当するブキ種の文字列に名前を追加してください。
